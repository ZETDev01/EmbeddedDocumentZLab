Phần I - Cài đặt Visual Studio Code (Từng bước chi tiết)

1. Cài đặt Visual Studio Code

Visual Studio Code là trình soạn thảo mã nguồn được phát triển bởi Microsoft. Nó nhẹ, nhanh chóng và có hỗ trợ rất tốt cho các extension.

Bước 1.1: Tải Visual Studio Code

  1. Mở trình duyệt web của bạn (Chrome, Firefox, Edge, Safari)
  2. Truy cập trang chính thức: https://code.visualstudio.com
  3. Bạn sẽ thấy nút Download (xanh lớn ở giữa màn hình)
  4. Nó tự động phát hiện hệ điều hành của bạn:
    • Windows: Download file .exe
    • macOS: Download file .dmg
    • Linux: Download file .deb hoặc .rpm tùy vào distro
  5. Nhấp nút Download để tải file về
Ghi chú: Kiểm tra file đã tải xuống trong thư mục Downloads của bạn

Bước 1.2: Cài đặt Visual Studio Code

Trên Windows:

  1. Mở thư mục Downloads (nhấn Windows key + E)
  2. Tìm file có tên VSCodeUserSetup-*.exe
  3. Nhấp đôi chuột vào file để chạy installer
  4. Chọn "I accept the agreement" (Tôi chấp nhận thỏa thuận)
  5. Nhấp Next để tiếp tục
  6. Nhấp Install để cài đặt (bỏ qua các tùy chọn nâng cao)
  7. Chờ cài đặt hoàn tất (khoảng 1-2 phút)
  8. Nhấp Finish để hoàn thành
  9. Visual Studio Code sẽ tự động mở

Trên macOS:

  1. Mở Finder, đi đến thư mục Downloads
  2. Tìm file VSCode-darwin-universal.zip
  3. Nhấp đôi để giải nén
  4. Kéo file Visual Studio Code.app vào thư mục Applications
  5. Mở Applications, tìm Visual Studio Code và nhấp đôi để khởi động

Trên Linux (Ubuntu/Debian):

  1. Mở Terminal (Ctrl + Alt + T)
  2. Chạy lệnh sau để cài đặt:
    sudo apt update sudo apt install code
  3. Nhập mật khẩu khi được yêu cầu
  4. Chờ cài đặt hoàn tất
  5. Khởi động: gõ code trong terminal

Bước 1.3: Kiểm tra Visual Studio Code đã cài xong

  1. Visual Studio Code đã mở, bạn sẽ thấy giao diện chính với các icon bên trái:
    • Biểu tượng file (Explorer)
    • Biểu tượng tìm kiếm (Search)
    • Biểu tượng git (Source Control)
    • Biểu tượng chạy/debug (Run & Debug)
    • Biểu tượng hộp (Extensions)
  2. Ghi chú phiên bản: Mở menu Help → About (hoặc Ctrl + , để Settings)
  3. Nếu bạn thấy đúng những biểu tượng trên, VSCode đã cài xong!

✓ Visual Studio Code đã sẵn sàng! Bạn đã hoàn thành bước đầu tiên. Tiếp theo, chúng ta sẽ cài PlatformIO IDE.

Phần II - Cài đặt PlatformIO IDE Extension (Từng bước chi tiết)

2. Cài đặt PlatformIO IDE Extension

PlatformIO là một extension mạnh mẽ giúp phát triển firmware nhúng. Nó hỗ trợ ESP32, STM32 và hàng trăm board khác.

Bước 2.1: Mở phần Extensions trong Visual Studio Code

  1. Visual Studio Code đã mở, nhìn sang bên trái giao diện
  2. Bạn sẽ thấy 5 biểu tượng dọc theo cạnh trái:
    • Biểu tượng đầu tiên: Explorer (thư mục)
    • Biểu tượng thứ hai: Search (tìm kiếm)
    • Biểu tượng thứ ba: Source Control (nhánh git)
    • Biểu tượng thứ tư: Run & Debug (debug)
    • Biểu tượng thứ năm: Extensions (các hình vuông) ← Nhấp vào đây
  3. Hoặc sử dụng phím tắt: Ctrl + Shift + X (Windows/Linux) hoặc Cmd + Shift + X (macOS)
  4. Bạn sẽ thấy thanh tìm kiếm xuất hiện với dòng chữ "Search Extensions"

Bước 2.2: Tìm kiếm PlatformIO

  1. Nhấp vào ô tìm kiếm (Search Extensions)
  2. Gõ chữ: platformio
  3. Danh sách extension sẽ lọc ra, bạn sẽ thấy:
    • "PlatformIO IDE" - Bởi PlatformIO (biểu tượng xanh)
    • Đây là extension chính thức
  4. Nhấp vào PlatformIO IDE (hàng đầu tiên)

Bước 2.3: Cài đặt PlatformIO IDE

  1. Trang chi tiết PlatformIO sẽ mở, bạn sẽ thấy nút "Install" bên phải (màu xanh)
  2. Nhấp nút Install
  3. Nút sẽ thay đổi thành "Uninstall", tức là đang cài đặt
  4. Chờ cài đặt hoàn tất (khoảng 1-3 phút tùy vào tốc độ mạng)
  5. Khi hoàn tất, nó sẽ hiển thị "PlatformIO IDE is enabled"

Bước 2.4: Khởi động PlatformIO lần đầu

  1. Sau khi cài xong, Visual Studio Code có thể yêu cầu reload
  2. Nhấp Reload nếu có
  3. PlatformIO sẽ khởi động lần đầu (khoảng dài vài phút)
  4. Bạn sẽ thấy thông báo "PlatformIO is initializing..."
  5. Chờ cho tới khi nó hoàn tất
  6. Xong! Bạn sẽ thấy biểu tượng PlatformIO (hình casa/nhà) xuất hiện ở thanh cạnh)

Bước 2.5: Kiểm tra PlatformIO đã cài xong

  1. Nhấp vào biểu tượng PlatformIO (hình nhà) ở cạnh trái
  2. Thanh PlatformIO sẽ mở, bạn sẽ thấy:
    • Quick Access
    • Proyects (Dự án)
    • Devices (Thiết bị)
    • Libraries (Thư viện)
  3. Nếu thấy những menu này, PlatformIO đã cài xong!

✓ PlatformIO IDE đã sẵn sàng! Bạn đã hoàn thành bước cài PlatformIO. Tiếp theo, chúng ta sẽ cài driver cho USB.

Phần III - Cài đặt Driver USB (CP210x, CH340, ST-LINK)

3. Cài đặt Driver cho USB

Board ESP32 và STM32 giao tiếp với máy tính qua cáp USB. Bạn cần cài driver cho chip USB để máy tính nhận diện board.

Bước 3.1: Kiểm tra board sử dụng chip USB nào

Trước khi cài driver, bạn cần biết board của mình sử dụng chip USB nào. Có ba loại phổ biến:

Chip USB Dùng trên Phổ biến
CP210x (Silicone Labs) ESP32 DevKit chính hãng, nhiều board cao cấp Rất phổ biến
CH340 (WinChipHead) ESP32 boards giá rẻ, STM32 clone boards Phổ biến nhất ở Việt Nam
ST-LINK STM32 (nạp firmware + debug) Bộ nạp chính hãng STM

Cách kiểm tra:

  1. Nhìn vào board phần cứng, tìm chip nhỏ gần cổng Micro USB
  2. Xem tên chip trên nó: CP210x, CH340, hay ST-LINK
  3. Nếu không tìm thấy, hỏi người bán hoặc coi tài liệu board

Bước 3.2: Cài driver CP210x (Silicone Labs)

Cho hệ điều hành Windows:

  1. Truy cập trang: https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers
  2. Tìm phần "Downloads" và chọn Windows
  3. Tải file CP210x Universal Windows Driver
  4. Giải nén file zip vừa tải
  5. Chạy file CP210xVCPInstaller_x64.exe (phiên bản 64-bit) hoặc phiên bản 32-bit nếu dùng Windows 32-bit
  6. Nhấp Install để cài đặt
  7. Khởi động lại máy tính

Cho hệ điều hành macOS:

  1. Truy cập trang Silicone Labs ở trên
  2. Tải macOS driver
  3. Giải nén file .zip
  4. Chạy file .pkg
  5. Làm theo hướng dẫn trên màn hình
  6. Khởi động lại máy tính

Cho Linux (Ubuntu/Debian):

  1. Mở Terminal (Ctrl + Alt + T)
  2. Chạy lệnh sau:
    sudo apt update sudo apt install cp210x
  3. Hoặc chạy lệnh: sudo usermod -a -G dialout $USER để thêm quyền truy cập USB
  4. Khởi động lại máy tính hoặc đăng xuất rồi đăng nhập lại

Bước 3.3: Cài driver CH340 (WinChipHead)

Cho hệ điều hành Windows:

  1. Truy cập trang: https://www.wch.cn/downloads/CH341SER_EXE.html
  2. Tải file CH341SER.EXE
  3. Chạy file, nhấp INSTALL
  4. Khởi động lại máy tính

Cho Linux (Ubuntu/Debian):

  1. Mở Terminal
  2. Chạy lệnh:
    sudo apt update sudo apt install ch341-dkms
  3. Hoặc thêm quyền:
    sudo usermod -a -G dialout $USER
  4. Khởi động lại máy tính

Bước 3.4: Cài ST-LINK (Cho STM32)

Cho Windows:

  1. Truy cập: https://www.st.com/en/development-tools/st-link-v2.html
  2. Tìm phần downloads, tải ST-LINK driver cho Windows
  3. Giải nén, chạy installer
  4. Khởi động lại máy

Cho Linux:

  1. Chạy lệnh:
    sudo apt update sudo apt install stlink-tools openocd
  2. Thêm quyền USB:
    sudo usermod -a -G dialout $USER
  3. Khởi động lại máy

✓ Driver USB đã cài xong! Bây giờ board của bạn sẽ được nhận diện khi kết nối USB.

Phần IV - Kết nối và kiểm tra Board

4. Kết nối và kiểm tra Board phần cứng

Sau khi driver cài xong, bạn sẽ kết nối board vào máy tính để kiểm tra nhận diện.

Bước 4.1: Kết nối board

  1. Lấy cáp Micro USB (hoặc USB Type-C tùy board)
  2. Cắm một đầu vào cổng USB của board
  3. Cắm đầu kia vào USB của máy tính
  4. Chờ vài giây để máy tính nhận diện

Bước 4.2: Kiểm tra trên Windows

  1. Nhấp chuột phải vào "This PC" (Máy tính này) → Manage (Quản lý)
  2. Chọn Device Manager (Trình quản lý thiết bị)
  3. Tìm phần "Ports (COM & LPT)"
  4. Bạn sẽ thấy thứ tương tự "COM X" hoặc "CH340 on COM X" (X là số cổng, ví dụ COM3, COM5)
  5. Ghi lại số cổng này - chúng ta sẽ dùng nó sau

Bước 4.3: Kiểm tra trên macOS

  1. Mở Terminal (Command + Space gõ "terminal")
  2. Chạy lệnh:
    ls /dev/tty.*
  3. Bạn sẽ thấy cái gì đó giống "/dev/tty.usbserial-xxxxx"
  4. Ghi lại cái này

Bước 4.4: Kiểm tra trên Linux

  1. Mở Terminal (Ctrl + Alt + T)
  2. Chạy lệnh:
    ls /dev/ttyUSB* /dev/ttyACM*
  3. Bạn sẽ thấy cái gì đó giống "/dev/ttyUSB0" hoặc "/dev/ttyACM0"
  4. Ghi lại cái này

✓ Board đã được nhận diện! Bây giờ bạn có thể bắt đầu lập trình với PlatformIO.

Phần V - Tạo tài khoản GitHub (Từng bước chi tiết)

5. Tạo tài khoản GitHub - Từng bước chi tiết

GitHub là nền tảng quản lý mã nguồn dùng để lưu trữ code, collaborative work và để kết nối với GitHub Copilot AI.

Bước 5.1: Truy cập GitHub

  1. Mở trình duyệt web
  2. Truy cập: https://github.com
  3. Bạn sẽ thấy trang chủ GitHub với nút "Sign up" (màu xanh ở góc phải trên)
  4. Nhấp nút Sign up

Bước 5.2: Điền thông tin đăng ký

  1. Nhập email của bạn (email hợp lệ)
  2. Nhấp Continue
  3. Tạo mật khẩu (phải có ít nhất 15 ký tự hoặc 8 ký tự kèm chữ cái + số)
    • Ví dụ: MyPassword123 (12 ký tự, có hoa, thường, số)
  4. Nhấp Continue
  5. Nhập username của bạn (cái tên hiển thị trên GitHub)
    • Ví dụ: myname123 hoặc john-dev
    • Username chỉ có chữ, số, dấu gạch ngang
  6. Nhấp Continue
  7. Chọn "Would you like to receive product updates and announcements via email?" → Chọn n (yes/no)
  8. Nhấp Continue

Bước 5.3: Xác minh là con người (Puzzle)

  1. GitHub sẽ yêu cầu bạn hoàn thiện một puzzle (ghép hình)
  2. Làm theo hướng dẫn trên màn hình
  3. Nhấp nút xác minh sau khi hoàn thành

Bước 5.4: Xác minh email

  1. GitHub sẽ gửi email xác minh đến email của bạn
  2. Mở email (kiểm tra thư mục spam nếu không thấy)
  3. Nhấp vào link xác minh đó
  4. Bạn sẽ quay lại GitHub, đây là trang dashboard
  5. Chúc mừng! Bạn đã có tài khoản GitHub!

✓ Tài khoản GitHub đã tạo xong! Tiếp theo, chúng ta sẽ liên kết Git với máy tính.

Phần VI - Liên kết Git với máy tính (SSH Key)

6. Liên kết Git với máy tính của bạn - SSH Authentication

Để đẩy code lên GitHub an toàn, bạn cần tạo SSH Key trên máy tính và liên kết nó với tài khoản GitHub.

Bước 6.1: Cài đặt Git (nếu chưa có)

Trên Windows:

  1. Truy cập: https://git-scm.com
  2. Nhấp Download, chọn Windows
  3. Chạy installer và làm theo hướng dẫn (bỏ qua các tùy chọn nâng cao)
  4. Khởi động lại terminal hoặc PowerShell

Trên macOS:

  1. Mở Terminal
  2. Chạy lệnh:
    brew install git
  3. Chờ cài đặt xong

Trên Linux (Ubuntu):

  1. Mở Terminal
  2. Chạy lệnh:
    sudo apt install git

Bước 6.2: Cấu hình Git toàn cục

  1. Mở Terminal (hoặc PowerShell/Command Prompt trên Windows)
    • Windows: Nhấp chuột phải, "Open PowerShell as administrator"
    • macOS: Terminal (Command + Space gõ "terminal")
    • Linux: Ctrl + Alt + T
  2. Chạy lệnh (thay tên và email của bạn):
    git config --global user.name "Your Name" git config --global user.email "your_email@example.com"
  3. Ví dụ:
    git config --global user.name "Tran Van A" git config --global user.email "tranabc@gmail.com"

Bước 6.3: Tạo SSH Key

  1. Mở Terminal/PowerShell
  2. Chạy lệnh:
    ssh-keygen -t ed25519 -C "your_email@example.com"
  3. Nếu SSH không được hỗ trợ, dùng:
    ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
  4. Terminal sẽ hỏi nơi lưu key:
    • Nhấn Enter để chấp nhận vị trí mặc định (~/.ssh/id_ed25519 hoặc ~/.ssh/id_rsa)
  5. Hỏi passphrase (mật khẩu add-on):
    • Bạn có thể để trống (nhấn Enter) hoặc tạo mật khẩu thêm
    • Để trống để tiện, nhuwg bớt an toàn
  6. SSH Key đã tạo xong!

Bước 6.4: Lấy SSH Public Key

  1. Mở Terminal/PowerShell
  2. Chạy lệnh để xem public key:
    cat ~/.ssh/id_ed25519.pub
  3. Hoặc trên Windows PowerShell:
    Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub
  4. Cả đoạn text bắt đầu bằng "ssh-ed25519..." sẽ hiển thị
  5. Sao chép toàn bộ đoạn này (Ctrl + C)

Bước 6.5: Thêm SSH Key vào GitHub

  1. Đăng nhập GitHub: https://github.com
  2. Nhấp ảnh đại diện ở góc phải trên → Settings
  3. Bên trái, chọn "SSH and GPG keys"
  4. Nhấp nút xanh "New SSH key"
  5. Nhập tiêu đề: My Computer SSH Key (hoặc tên máy tính của bạn)
  6. Dán đoạn public key vừa sao chép vào ô "Key"
  7. Nhấp "Add SSH key"
  8. GitHub có thể yêu cầu xác minh mật khẩu - nhập mật khẩu GitHub của bạn
  9. SSH Key đã thêm vào GitHub!

Bước 6.6: Kiểm tra kết nối SSH

  1. Mở Terminal/PowerShell
  2. Chạy lệnh:
    ssh -T git@github.com
  3. Terminal hỏi "Are you sure you want to continue..." → Gõ yes
  4. Nếu thấy dòng "Hi [username]! You've successfully authenticated..." → Thành công!

✓ Git đã kết nối với GitHub! Bây giờ bạn có thể clone, push, pull code từ GitHub.

Phần VII - Cài đặt GitHub Copilot AI (Từng bước chi tiết)

7. Cài đặt GitHub Copilot AI - Hỗ trợ lập trình bằng AI

GitHub Copilot là một AI giúp bạn viết code nhanh hơn. Nó có thể tự động hoàn thành code, gợi ý hàm, và giải thích code cho bạn.

Bước 7.1: Cài đặt GitHub Copilot Extension

  1. Mở Visual Studio Code
  2. Nhấp biểu tượng Extensions (5 hình vuông) ở cạnh trái
  3. Gõ "github copilot" trong ô tìm kiếm
  4. Bạn sẽ thấy "GitHub Copilot" (official, bởi GitHub)
  5. Nhấp vào nó
  6. Nhấp nút "Install" (xanh)
  7. Chờ cài đặt xong (vài giây)

Bước 7.2: Cài GitHub Copilot Chat (thêm tính năng chat)

  1. Vẫn trong Extensions
  2. Tìm "GitHub Copilot Chat"
  3. Nhấp Install

Bước 7.3: Đăng nhập GitHub trên Visual Studio Code

  1. Sau khi cài xong, Visual Studio Code sẽ yêu cầu bạn đăng nhập GitHub
  2. Nhấp nút "Sign in with GitHub to use Copilot" (nếu thấy)
  3. Hoặc: Nhấp Ctrl + Shift + P (mở Command Palette)
  4. Gõ: "GitHub Copilot: Authorize with GitHub"
  5. Nhấp vào lệnh đó

Bước 7.4: Cấp quyền cho Copilot

  1. Trình duyệt sẽ mở GitHub login page
  2. Đăng nhập GitHub (nếu chưa)
  3. GitHub sẽ yêu cầu cấp quyền cho Visual Studio Code:
    • "Authorize GitHub Copilot for VS Code"
  4. Nhấp "Authorize"
  5. Bạn sẽ thấy "Device activation successful"
  6. Quay lại Visual Studio Code

Bước 7.5: Kiểm tra Copilot đã sActivate

  1. Mở file code bất kỳ (hoặc tạo file .cpp mới)
  2. Bắt đầu gõ code
  3. Bạn sẽ thấy gợi ý Copilot xuất hiện (nền xanh nhạt)
  4. Nhấn Tab hoặc Enter để chấp nhận gợi ý
  5. Nhấn Escape để từ chối

Bước 7.6: Sử dụng Copilot Chat để hỏi câu hỏi

  1. Nhấn Ctrl + Shift + I (hoặc Cmd + Shift + I trên macOS)
  2. Hoặc: Nhấp biểu tượng chat Copilot ở cạnh trái (nếu được thêm)
  3. Ô chat sẽ mở
  4. Bạn có thể hỏi câu hỏi bằng tiếng Anh:
    • Ví dụ: "How to blink LED on ESP32?"
    • Ví dụ: "Explain this code for me"
    • Ví dụ: "Generate a code to read ADC value"
  5. Gõ câu hỏi, nhấn Enter
  6. Copilot sẽ trả lời trong ô chat
Ghi chú về GitHub Copilot miễn phí và trả phí:
  • GitHub Copilot có bản miễn phí giới hạn (hàng tháng)
  • Có bản trả phí $10/tháng (unlimited)
  • Sinh viên được dùng miễn phí với tài khoản GitHub Student Pack
  • Trang đăng ký: https://github.com/copilot (sẽ thấy tuỳ chọn giới hạn hay không giới hạn)
